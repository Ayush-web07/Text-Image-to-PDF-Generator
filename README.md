# 📄 Text Image to PDF Generator

A professional Django web application that converts text and images into beautifully formatted PDF documents.

## Features

- Upload Images
- Convert Text to PDF
- OCR Support
- PDF Download
- Clean UI
- Django Backend

## Technologies

- Python
- Django
- HTML
- CSS
- JavaScript
- Bootstrap

## Installation

```bash
git clone https://github.com/Ayush-web07/Text-Image-to-PDF-Generator.git

cd Text-Image-to-PDF-Generator

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
